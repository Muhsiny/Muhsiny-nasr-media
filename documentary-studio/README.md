# استدیوی مستند — Documentary Studio

نسخهٔ 0.1: اپ Android فارسی/دری برای مدیریت پروژهٔ مستند و اتصال به موتور محلی تولید رسانه.

## اصل طراحی
- رابط RTL فارسی/دری
- پروژه و سناریو روی دستگاه ذخیره می‌شود
- سبک بصری پیش‌فرض: واقع‌گرایانه، مستند، سینمایی
- عدم قفل‌شدن به یک سرویس ابری
- موتور تولید تصویر/ویدیو از طریق URL شبکهٔ محلی قابل تعویض است

## قرارداد موتور محلی
- `GET /system_stats` برای تست سلامت
- `POST /docstudio/generate` با JSON شامل `type` و `prompt`

مرحلهٔ بعد: موتور Python محلی برای ComfyUI/FLUX و ویدیوی Wan/Hunyuan و سپس TTS فارسی محلی.
